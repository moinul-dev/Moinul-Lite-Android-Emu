# Moinul Lite Android Emulator (Google GMS Edition)

A lightweight Python Tkinter controller and automated PowerShell setup for running Google's official Android Emulator with **Google Play Services (GMS)** on Windows without heavy Android Studio bloat.

## Features
- **Auto RAM Optimizer:** Closes heavy background browsers before booting.
- **Official Google Play Store:** Uses Google's `google_apis_playstore` x86_64 system image.
- **One-Click APK Installer & UI Speed Booster:** Installs local APKs and disables system animations via ADB.

## Usage
1. Run `.\setup.ps1` in PowerShell to download the SDK and configure `Moinul_Lite_GMS`.
2. Launch the controller: `python android_emu_manager.py`
